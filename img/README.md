## UI 改修が終わったら（差し替え手順）

大西様の指示（2026-08-08）: **UI 改修が完了したら、最新の画面で作り直す。**

1. 最新の UI で `../mockups/list.html` `../mockups/detail.html` を作り直す
   （または、ダミーデータを入れた検証環境から直接スクリーンショットを撮る）
2. 同じファイル名で `screen-detail.png` `screen-list.png` を上書きする
3. サイト側の HTML は**触らなくてよい**（ファイル名で参照しているため）

## 差し替え時に必ず確認すること

- 顧客名・住所・電話番号・メールアドレスが**すべてダミー**になっているか
- ヘッダー右上の**会社名がダミー**（例: 株式会社サンプル工務店）になっているか
  → 関連会社の社名は公開物に出さない方針
- 担当者名がダミーになっているか
- 金額が実在の契約金額でないか

## 書き出しの設定

- 幅 1400px、`device_scale_factor=2`（Retina 相当）
- 生成スクリプトの例は `Retera販促` セッションの作業ログを参照
